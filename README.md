# DazzleCommerce — clone of dazzlecommerce.com

Next.js (App Router, TypeScript) clone of https://dazzlecommerce.com/, built page by page, section by section, word by word. Source site is owned by our company.

- Full page register: `RECORD_REGISTER.md` (177 pages)
- Progress summary: `STATUS.md`
- Per-page source extraction: `clone-plan/`

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```
